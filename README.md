# 张语桐 · Yutong Zhang

中英双语个人学术主页，关注大语言模型评测、可信人工智能与金融科技。

访问：https://yutong-cloud.github.io/

本仓库 `gh-pages` 分支通过 GitHub Actions 发布静态页面，无需安装依赖。

- `index.html`：页面结构
- `profile.js`：双语个人资料、动态、研究与荣誉
- `styles.css`：配色和响应式版式
- `app.js`：主题、语言、筛选、弹窗和复制功能
- `assets/`：个人照片、简历和论文 PDF

设计结构参考用户指定的 [WowPage](https://github.com/WD7ang/WowPage)、[Weidong Tang](https://wd7ang.github.io/) 和 [Selen Su](https://selen-suyue.github.io/)，页面代码与研究示意图重新制作。个人资料和 ESG 附件由主页作者提供。
